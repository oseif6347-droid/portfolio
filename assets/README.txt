This folder is for your images and files, such as:

- profile-photo.jpg  (a professional headshot, used in about.md if you add one)
- resume.pdf         (a downloadable copy of your resume/CV)
- project screenshots (e.g. project-1.png, project-2.png)

The current index.html does not reference any files here yet — it uses a
text-only, code-editor-style design so the site works immediately without
images. If you'd like a photo or project screenshots added to the layout,
drop the files in this folder and they can be wired into the HTML/CSS.
